# 🌏 India Info Page

This project is a simple **frontend page** showcasing information about India.  
It uses **HTML and CSS**, including **CSS animations** for text and content blocks, to make the page interactive and visually appealing.  

This is perfect for **learning CSS styling, layout, and animations**.

---

## 📌 Features
- Displays **key facts about India** in readable blocks  
- Highlights **letters of "INDIA" individually** for animation purposes  
- Uses **CSS animations** to create visual effects  
- Fully responsive and beginner-friendly  
- Ideal for practicing **HTML, CSS, and simple animations**

---

## 🛠️ Tech Stack
- **HTML5** – page structure  
- **CSS3** – styling and animations
