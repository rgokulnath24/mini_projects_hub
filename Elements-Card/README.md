# 🌐 Inline vs Block vs Inline-Block Demo

This repository demonstrates the difference between **Inline, Block, and Inline-Block HTML elements**.  
It’s a beginner-friendly project to **understand how elements behave in a web page** and how CSS `display` property affects layout.

---

## 📌 Features
- Clear demonstration of **inline, block, and inline-block elements**  
- Easy-to-read **HTML and CSS structure**  
- Styled buttons to visualize **inline-block behavior**  
- Beginner-friendly learning resource  
- Responsive and readable layout

---

## 🛠️ Tech Stack
- **HTML5** – page structure  
- **CSS3** – styling and layout  
- **Optional frameworks** – can integrate Bootstrap or Tailwind if needed
