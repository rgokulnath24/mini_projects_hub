# Random Joke Generator 🎲

A simple web project that displays a random joke when you click a button.  
It also includes smooth animations for the container, button, and output text.

---

## Features

- Randomly displays jokes from a predefined list.
- Smooth animations:
  - Container slides in from the left.
  - Button slides up on page load.
  - Joke output slides up and fades in each time it updates.
- Fully responsive and lightweight.
- Easy to extend with more jokes.
